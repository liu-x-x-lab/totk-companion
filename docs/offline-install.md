# 安卓离线安装与使用

安装包：`hyrule-companion-0.1.0-android-offline.apk`。应用名称为“海拉鲁探险手册”，包名 `app.hyrule.companion`。支持 Android 8.0（API 26）及以上，建议使用已更新的 Android System WebView / Chrome。

## 在安卓手机上安装

1. 下载 APK 到手机，在文件管理器或浏览器下载列表中打开。
2. 手机如提示，允许当前浏览器或文件管理器“安装未知应用”，然后完成安装。
3. 打开“海拉鲁探险手册”即可使用。可以开启飞行模式检验地表 / 天空 / 地底、拖动和双指缩放、筛选怪物、查装备。

这是本地签名的试用安装包，不经过应用商店。安装包不申请网络或共享存储权限，三层 2–7 级地图瓦片、54,793 条固定地点、310 件基础装备及对应图片、730 个中文地名和 35 篇任务教程都直接包含在 APK 中。地图第一次打开新区域时也不需要下载。

## 地图与记录

- 地图铺满底部导航上方的屏幕，支持 1–64 倍缩放；最小倍率仍填满画布，边缘拖动不露出空白。横竖屏变化及图层切换保留视野。
- 顶部工具、分类及地点详情可以收起，放大后可展开密集标记。字号为手机可读的紧凑尺寸；地点详情打开时，缩放工具在面板上方继续可用，目标定位在工具与详情之间的地图区域。
- “地名”按钮可开关中文文字，缩放时文字保持清楚。地图搜索可查中文村镇、湖泊、岛屿和遗迹。
- “任务”含 253 个目录条目，其中 35 篇离线教程覆盖全部 23 条主线与常用功能任务。可查接取、前置、分阶段操作并手动勾选，地点按钮跳回地图。索引任务标明教程待整理。
- “装备”顶部的“防具升级备料”可添加多件防具，选择当前和目标星级，自动合并材料与卢比。填写已有量，查看还缺多少；升级后手动调整当前星级及材料。
- 收藏、手动耐久、任务阶段、防具备料计划和已有材料数量保存在手机的应用数据中，关掉应用后仍可继续使用。
- 在收藏页点“导出记录”，通过系统文件选择器保存 JSON；“导入备份”打开已有 JSON，校验后确认替换。地点 / 装备 CSV 也可选择保存位置。
- 卸载应用会清除本机记录；换手机或卸载前请导出备份。后续更新使用相同包名和签名密钥，以支持覆盖安装。
- 来源链接会在手机浏览器打开，查看外部网页需要网络；应用内地图、资料与本机记录可以离线使用。

装备基础耐久来自资料表；实际剩余耐久由玩家手动记录。地图保存的是固定放置对象和社区探索索引，不读取主机存档。来源与游戏版本边界见同项目的 `sources.md`、`equipment-sources.md` 与 `quest-sources.md`。

## 完整离线网页 ZIP

`hyrule-companion-0.1.0-offline-web.zip` 包含相同网页资源和来源说明。用于电脑本地运行或二次打包，安卓手机优先安装 APK。

解压后安装有 Python 3 的电脑可运行：

```bash
python3 serve-offline.py
```

用浏览器打开 `http://127.0.0.1:4178/`。服务器只在本机提供包内文件，运行时不访问外部资源。不能直接双击 `index.html`，因为浏览器需要通过本机 HTTP 读取 JSON 和脚本模块。

## 校验与重新构建

交付目录中的 `SHA256SUMS.txt` 和 `package-manifest.json` 记录 APK / ZIP 大小、SHA-256、地图数量与构建时间。`apk-verification.txt` 保存 APK 签名、包名、Android 版本和权限检查结果。

```bash
python3 -m pip install -r scripts/requirements-tools.txt
python3 scripts/sync-map-tiles.py
npm run check
npm run test:e2e
npm run test:offline
python3 scripts/build-android.py --sdk /home/liuwei/Android/Sdk
```

构建需要 Node.js 22.12+、JDK 17、Android platform 35 和 build-tools 34.0.0。打包脚本先校验三层地图与装备图片，再构建网页、生成签名 APK，逐个校验 APK 内资源。签名密钥仅保存在 `.cache/android/signing/`，不进入源码仓库。请保留这个目录以便后续覆盖升级。

已具备自动化的手机浏览器与断网资源测试、原生代码编译和 APK 签名 / 资源校验。当前环境没有连接安卓真机，安装、系统文件选择器和真机手势仍需在手机上验证。

## 在局域网提供安装包

完成构建后运行 `python3 scripts/serve-releases.py --port 8788`。服务器仅提供 `releases/` 中的安装包和说明，监听 `0.0.0.0:8788`；手机与开发电脑处于同一局域网时，打开开发电脑 IP 对应的这个端口即可下载。实际地址随开发电脑 IP 变化。
