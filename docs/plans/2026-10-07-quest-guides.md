# 任务线与阶段教程

用户要能查“在哪里接、去哪里、怎么做”，包括会跨多个阶段的任务。新增底部“任务”入口，保持现有地图、装备、怪物和收藏。中文任务按主线、情节挑战、神庙挑战和支线分类，支持搜索与进度筛选。

任务标题及稳定 ID 对照 1.2.1 游戏文本快照，类别对照公开任务清单。教程使用自行编写的行动步骤，不把完整剧情日志直接当攻略。完整主线和常用功能任务优先提供步骤；仅有索引的条目明确显示教程覆盖状态，避免冒充全任务攻略。

每份教程给出起点、前置条件、准备、分阶段目标与动作。地点绑定现有真实地名 ID，可跳地图；村镇或遗迹位置明确为地点定位，不伪装成 NPC 精确坐标。阶段勾选为玩家手动进度，可以取消、回到未完成阶段，并通过现有备份导出 / 导入。旧版本没有任务字段的备份继续可读。

列表默认先显示有教程的任务，按建议阶段排序；详情逐阶段展开，默认展开当前阶段，后续内容由玩家主动查看。跨任务的下一步可打开相关教程。APK 将目录与全部已有教程一起打包，断网无需外部攻略站；参考来源可选在浏览器查看。

验证分类数量、教程有可执行步骤、地图关联存在、关键前置和耐力要求、进度持久化及旧备份迁移；验证 360 px 手机任务页、跨页面地图定位、阶段完成及导出恢复。
