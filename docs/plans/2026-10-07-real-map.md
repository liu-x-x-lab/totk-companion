# 三层真实地图与全量地点 Implementation Plan

> **For Codex:** 用户已明确要求真实资料、分类标记、坐标与天空 / 地表 / 地底，直接在当前项目完成。

**Goal:** 用可追溯的真实世界坐标替换示意地图，并提供完整固定怪物地点与分类探索元素。

**Architecture:** 原始资料通过 Python 导入器压缩成带字典的本地 JSON 和 CSV，前端异步读取。使用三层地图瓦片、统一坐标变换、可视范围渲染和屏幕网格聚合；放大后展开，保留所有原始对象记录。

**Tech Stack:** 现有 React / TypeScript / Vite，Python 标准库、WebP 瓦片、Node 内置测试与 Playwright。

---

1. 创建 `scripts/sync-data.py`、`docs/sources.md` 和数据清单，核验怪物查询不会混入关联对象。
2. 下载怪物、资源、装备、NPC、动物、左纳乌装置等固定对象以及全部探索标记，输出 `public/data/points.json`、`coordinates.csv` 和 `manifest.json`。
3. 扩展 `src/types/domain.ts`、建立 `src/data/catalog.ts`；仓库异步读取真实索引，保留来源与原始坐标。
4. 替换 `MapCanvas.tsx` 示意图为本地概览和在线高清瓦片；地图宽高改为 6:5；最大缩放 64 倍；可视范围渲染与聚合。
5. 更新地图和怪物页，支持西诺克斯 / 人马快捷筛选、完整分类树、名称与坐标搜索、坐标复制和分页结果。
6. 更新需求、README 和数据契约，说明固定对象范围与动态状态边界；保留装备资料核验状态。
7. 运行类型检查、业务测试、手机浏览器测试；检查三层瓦片、已知坐标、聚合展开、持久化和没有伪造数值。
