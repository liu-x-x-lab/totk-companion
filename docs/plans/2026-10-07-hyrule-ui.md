# Hyrule UI Implementation Plan

**Goal:** 让现有手机 App 呈现海拉鲁探险手册的韵味，并交付可打开的预览和实际截图。

**Architecture:** 保持现有 React 页面和数据流，用 CSS 和原创 SVG 改善视觉。装备图标按 Actor ID 从固定上游快照同步到本地；领域解码器为基础和强化条目提供同一图标关联。

**Tech Stack:** React、TypeScript、Vite、CSS、SVG、Python 标准库、Playwright。

---

### Task 1: 同步装备图标

创建 `scripts/sync-equipment-icons.py`，读取 `public/data/equipment.json` 的 310 件基础装备和上游 Git 树，要求每个 ID 匹配唯一图片。下载到 `public/images/equipment/`，校验 PNG 格式、尺寸，写入来源清单 `public/data/equipment-icons-manifest.json`。记录使用方法与来源于 `docs/ui-assets.md`。

### Task 2: 图标关联与页面接入

修改 `src/types/domain.ts`、`src/data/equipment.ts`，用 `iconId` 记录图标对应基础 ID，让强化防具继承关联。创建 `src/components/EquipmentArt.tsx`，使用本地图片、延迟加载和异常回退，接入装备页及收藏页。保持存档 ID 和数值不变。

### Task 3: 视觉主题

创建 `public/ui/ancient-ring.svg` 和 `public/ui/engraved-rule.svg` 原创纹样，更新应用图标。修改 `src/styles/global.css` 中页眉、标题、图层标签、地图框、卡片、统计、底部导航样式。保持顶部和底部安全区以及手机触控尺寸。

### Task 4: 验证与交付

运行 `npm run check` 和 `npm run test:e2e`。为真实图标、强化关联和失败回退增加必要浏览器检查。使用 `scripts/capture-preview.mjs` 保存地图、装备、天空和地底真实截图于 `docs/previews/`，检查手机实际效果和资源错误。执行 `git diff --check`、审阅提交；保持 5178 端口本地预览运行。
