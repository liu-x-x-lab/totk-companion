# Offline Package Implementation Plan

**Goal:** 保持全屏地图、无留白缩放和手机可读字号，制作不依赖外部服务器资源的离线手机包。

**Architecture:** 三层 2–7 级原生瓦片、地点、装备和图标全部在构建时保存到本地。地图只请求包内路径，手机安装包复用同一 Web 界面，通过本地资源拦截提供页面和资源，不申请网络权限。另输出包含资源、来源和运行说明的 ZIP。

**Tech Stack:** React、TypeScript、Python、Android SDK / Java / WebView、Playwright。

---

1. 修改 `geometry.ts`，将覆盖视口的比例作为最小值，拖动边界不预留空隙。调整视口变化和图层切换以保持位置，并为这些行为添加几何及手机测试。
2. 完善字体为手机可读的紧凑尺寸，保留大地图和浮动可收起面板。
3. 创建 `scripts/sync-map-tiles.py`，下载三层全部原生 2–7 级瓦片，记录尺寸、SHA-256 和来源；支持断点续传与完整性检查。
4. 修改 `Tiles.tsx`，使用本地高清瓦片，不回退外部服务。更新来源和需求文档。
5. 用户已确认安卓：构建 Android 本地资源容器和打包脚本，在 SDK 已有环境中生成签名测试 APK；不依赖后端，不将签名密钥纳入仓库。通过系统文件选择器导入备份、导出 JSON / CSV，使用原生剪贴板复制坐标。
6. 使用正式构建资源在断网浏览器环境验证三层切换、高清放大、搜索及装备数值。运行 `npm run check`、`npm run test:e2e`，核对 APK 内资源并验证签名，生成 ZIP、SHA-256 和实际页面截图。
