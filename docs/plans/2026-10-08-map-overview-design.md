# 手机远景地图设计

日期：2026-10-08。范围：用户持续授权的地图体验优化、离线 Android 包更新。

## 已复现的问题

390 × 844 视口，最低 100% 倍率、地表“全部元素”显示 108 个聚合数字；不被顶部和底部面板遮挡的区域仍有 53 个，存在 5 对触控矩形重叠。点击一个可触达的聚合只进入 200%，同时创建 130 个标记。默认大型怪物和神庙也有相邻网格触控区域重叠。360 px 同样可复现。证据保存于忽略的 `.cache/verification/zoom-density-baseline.json` 和截图。

根因：聚合单元仅按屏幕面积把数量控制在 150 以下，没有远近层级；相邻网格的实际质心可能很近，44 px 触控目标仍会重叠；每次聚合点击仅固定乘二，没有按目标区域大小定位；没有独立的双击 / 双触放大入口。

## 方案选择

1. 按倍率控制密度，远景用少量区域图标，近景逐步展开。保留空间分布与所有数据，适合手机，采用。
2. 远景完全隐藏地点。地图最干净，但无法直接选择有地点的区域，不采用。
3. 远景用热力图。需要新增绘制与颜色解释，无法直接识别地点类型，本轮不引入。

## 行为与边界

- 小于 4 倍是远景，普通聚合预算最多 32 个；4–12 倍预算 64；12 倍起预算 120（为原有选中点预留一个）。每一层保持 44 px 触控区域，相邻聚合质心太近则合并；完整点位归属保留，选中点独立显示。
- 远景聚合使用固定屏幕尺寸的叠层区域图标，隐藏原始数字；中近景显示最多三字符 `99+` 的数量徽记，精确数量仍在无障碍名称和重合地点列表。
- 地名、神庙 / 树根 SVG、完成徽记、地图坐标和完整筛选列表保留。类别无结果时不创建地点标记。
- 点击聚合参考其真实点位范围、可用视口和当前倍率定位；一次至少推进两倍，从远景一次进入至少 4 倍，以可用区域中心为定位锚点。最多 64 倍时仍打开重合地点列表。
- 空白地图短时间内两次轻点 / 双击，围绕该处放大进入区域。拖动、双指手势、取消事件与点击标记不能被识别成双击。
- 提示改为“远景点区域标记或双击放大”，不依赖用户读密集数字。
- 原始资料、稳定 ID、存档格式、包名、签名、origin 均不变。不引入网络依赖。

## 验证

真实资料和人工边界分布的单元测试验证：远景预算、数据无损、相邻网格触控距离、选中点、逐级展开和聚合定位边界。

手机 E2E 验证 360 / 390 px 的全部元素、呀哈哈、神庙、三层切换、点一次聚合和连续两次轻点；同时检查拖动和双指不会误放大。运行完整 `npm run check`、`npm run test:e2e` 和生产断网验证，最后以原签名构建 0.1.4 / versionCode 5，复核局域网下载。

不声称 Android 真机验证或恒定帧率。本轮浏览器截图为真实 React 页面。
