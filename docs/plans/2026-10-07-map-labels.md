# 离线地图地名

用户需要地名直接出现在底图上。三层地图增加独立地名文字层，默认显示，提供 44 px 触控的“地名”开关；怪物及地点分类不会隐藏地名。

以社区静态地点索引的 MessageID 匹配公开游戏文本快照中的简体中文名称，保留英文、原始坐标、来源 ID 和版本说明。使用上游 ZoomLevel 与实际图层信息，修正恰好位于 1000 米且错误归到地表的天空地标。重复剧情入口合并为一个显示标签，不删除原始地点记录。

缩小时显示地区、村镇与主要地标，放大后逐步出现山、河、遗迹、天空岛及地底矿场。文字采用与地图相机相反的比例缩放，手机上保持固定可读字号，并用碰撞检测减少重叠；文字不抢地图手势或标记点击。

验收：三层地名对应图层，中文搜索能找村镇、地区及地标；“地名”开关仅影响文字；放大后增加附近名称，字号不随倍率膨胀；断网时仍能读到中文地名。截图和安卓版都包含新文字层。
