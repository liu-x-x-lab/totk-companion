# 海拉鲁探险手册视觉设计

日期：2026-10-07。用户希望看到当前效果，并让手机界面更有《王国之泪》的韵味。本次在既有三层地图、装备资料和本地收藏上直接完善视觉。

## 方向选择

考虑过三种方向：纯纸质攻略册、深色游戏菜单、玉石与纸页结合的探险手册。选择第三种：深玉石绿的页眉与导航，暖米色的内容页，少量金色边线和原创古代圆环纹样。纸页保证地图筛选和装备数字的可读性，深色装备图标底座接近游戏物品栏的观感。

## 页面与资源

- 页眉保留名称、三层地图入口提示和数据载入状态。原创圆环和几何石刻作背景，不新增占据地图空间的宣传区。
- 天空、地表、地底标签保持现有触控尺寸，选中状态改成玉石色、细金边和明确图标。
- 地图保持真实地形；加强外框、罗盘、缩放控制和坐标区域，装饰不覆盖标记。
- 装备和收藏显示与装备 Actor ID 精确匹配的本地物品图标。上游固定到提交快照，记录原始路径、校验值和图片尺寸。强化防具复用对应基础防具图标；没有来源图标的历史条目保留类别符号。
- 所有页面沿用同一套纸页、刻线、标题印记和导航风格。保留中文标题与无障碍名称。

## 验收

360 px 手机竖屏无横向溢出，点击目标至少 44 px；三层地图切换、缩放、分类、坐标搜索和装备收藏仍可使用。运行现有业务和手机浏览器检查，检查图片真实载入，生成真实页面截图和局域网预览地址。当前授权范围是本地预览，不新增线上部署。
