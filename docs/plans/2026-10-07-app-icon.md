# 原创探索图标实施计划

用户已允许改用其他元素绘制 App 图标。采用与现有界面一致的玉石绿、暖金和象牙白，主体为原创地图、探索剑与导航光点，外围为断续圆环和几何刻线。图形集中在自适应图标安全区域，网页与安卓共用同一矢量形状。

内置 imagegen 已尝试新方案，暂未返回可读取的新文件；发现的旧角色图不是本次结果，不接入。最终生产资源用项目原有 SVG / Android VectorDrawable 结构绘制，不使用 CLI / API 替代，也不将矢量资源标为 AI 生成位图。

1. 重绘 `public/icons/app.svg`，新增可追溯资源清单；将相同路径转换到 `android/res/drawable/ic_emblem.xml`。
2. 从 SVG 导出网页 192 / 512 px PNG，更新 Manifest。保存圆形、方圆形和 48 px 预览，确认裁切不损失主体。
3. 版本升至 0.1.3 / versionCode 4，更新需求与安装说明。保留原包名、签名、存储 origin 和记录结构。
4. 运行 `npm run check`，检查实际网页 Logo、Manifest 图片和原生资源编译；构建脚本继续执行生产断网与 APK 全资源校验。
5. 对照旧版签名，核对局域网完整下载及 SHA-256，保存验收说明、提交源码，并提供新 APK。
