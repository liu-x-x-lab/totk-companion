# 装备固定属性补充设计

日期：2026-10-07。用户已要求补充装备与固定基础耐久，沿用现有装备图鉴与本地记录方案直接实现。

## 资料与方案

采用 Phil 发布的 TotK Data Spreadsheet，导入 112 个近战武器条目、30 种弓、33 种盾与 135 件基础防具。以 Echocolat 原始整理表对照数值；中文名称来自 TotK Savegame Editor 的中文词条，保留英文名和原始 Actor ID。

比较过三种方式：完整本地属性库便于手机查看和重复生成，本次采用；人工逐件补写维护成本较高且难以证明覆盖率；运行时访问资料站会让装备页依赖网络与站点结构。本次继续通过本地 JSON 资料仓库读取。

## 数据与展示

保留游戏显示攻击值和内部攻击参数，默认显示前者。腐朽与无腐蚀武器独立列出。基础耐久不包含耐久提升词条与融合增加值；这些字段在详情分别展示。魔王之弓使用攻击范围与红心规则，大师之剑标注状态变化，不把所有装备简化成同一种公式。

防具按基础装备归并，显示基础防御、各强化等级防御、材料和卢比费用；不创建防具耐久。旧强化 Actor ID 保留为可解析的别名，原收藏及手动记录不删除。仅供事件或 NPC 使用、没有独立属性资料的旧名称保留为历史条目，不纳入基础图鉴。

装备卡保留中文、英文和 ID 搜索。新建手动耐久记录默认填入已知基础耐久，仍允许用户按自己装备的词条与融合情况修改最大值和剩余值。

## 来源与验证

生成独立装备清单、来源地址、快照 SHA-256、覆盖数、数值对照结果与来源差异说明。资料表未统一声明游戏版本，因此不宣称支持所有版本。朽坏大师之剑的旧表耐久 6 与 Phil 表 4 不同，采用 Phil 的 4，并明确保留差异说明。

测试覆盖真实典型数值、腐朽 / 无腐蚀分离、游戏显示攻击值、魔王之弓范围、防具强化材料、中文搜索、默认耐久、旧收藏解析以及手机无横向溢出。执行类型检查、业务测试、构建和手机浏览器测试。
