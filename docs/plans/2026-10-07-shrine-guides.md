# 神庙视频与地图图标实施计划

**目标：** 152 座神庙详情都有对应的中文解谜视频分集，提供抖音名称搜索；神庙、树根改用对应的游戏地图符号。

**架构：** 神庙资料随离线包保存，按 `Dungeon000`–`Dungeon151` 与稳定地点 ID 精确关联。简体中文名和谜题名来自固定 1.2.1 游戏文本，视频来自公开完整攻略合集的分集元数据；外部视频仅在玩家点击时交给浏览器或平台。图标为已核对社区游戏地图 SVG 的本地资源，取消模糊光晕和原来的圆形底座，保留 44 px 点击范围与固定屏幕尺寸。

**技术：** React、TypeScript、Vite、Python、Playwright，沿用 Android WebView 包名、签名和玩家记录。

## 取舍与边界

- 采用逐神庙对应的 B 站中文分集，加抖音搜索入口。已找到的合集含 152 个神庙分集和 2 个索引分集；抖音尚未找到可逐一核对的完整合集。
- 单纯提供搜索无法保证点开就是目标神庙；将视频嵌入地图会引入网络依赖和额外加载。故本轮保存本地目录，用户主动打开外部平台。
- `title-matched` 只表示神庙全名与平台分集标题、CID、页码相符，不声称逐个观看或实测。抖音直接视频为 `null`，搜索不能当作已核验视频。
- 不下载视频，不添加权限，不改存档结构。视频内容与平台可用性可能变化，详情中保留搜索入口。
