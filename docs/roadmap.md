# 研发路线

## 阶段 0：项目初始化（本次）

建立独立目录和 Git 仓库。初始化 React + TypeScript + Vite、手机界面、示例地图与资料模型、地图手势、搜索筛选、收藏、手动耐久记录和本地备份。写清需求、数据边界和启动方式，验证构建与手机交互。

## 阶段 1：真实地图资料（已接入）

已记录真实数据来源并接入天空、地表、地底地图、固定怪物和探索地点。坐标变换、分类、聚合、搜索和 CSV 已实现。数据以社区资料展示，保留原始坐标和来源；示例资料已退出运行仓库。

下一步独立核验装备基础属性、强化与融合规则，补充中文地点译名，并继续对照游戏资料抽样检查。动态生成对象与实时状态使用独立方案。

地图验收已通过：用户能找到具体怪物地点、放大查看邻近地形、查看坐标与来源。装备名称已接入，真实基础耐久和其他属性仍待核验。

## 阶段 2：日常探索工具

在现有神庙、鸟望台、洞窟入口、材料筛选之上，增加已探索标记、剧透开关、武器对比和经过核验的融合规则。完善主屏幕安装、应用壳缓存与资料更新提示；备份恢复已实现。

## 阶段 3：离线与安装包

按地区下载离线瓦片、存储管理与增量更新。根据用户实际手机选择是否封装 Android / iOS；有多设备同步需求时再加入后端和账号。
