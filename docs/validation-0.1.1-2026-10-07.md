# 0.1.1 地图优化与交付验收

日期：2026-10-07。对应用户 Android 0.1.0 截图反馈：缩放不流畅、地名 / 小图标模糊、地底出现阶梯状深绿色缺块。

## 最终改动

- 地形改为原生图片瓦片合成，图片层先裁切到视口再移动；取消巨大世界图层的永久缩放。64 倍时图像容器仍只有 393 × 776 CSS px，单个合成容器不超过视口。
- 地名与 SVG / 汉字标记独立定位，字体和 44 px 触控区域不随地图缩放；按物理像素对齐，减少模糊阴影。
- 高清级别包含 DPR；通常手机使用原生屏幕密度，超大视口有细节资源预算。源图片到达原生第 7 级后，继续放大仍受原图分辨率限制。
- 瓦片完成解码才显示；概览常驻、旧图回退、一圈预取、最多 8 个并发、失败有限重试。缓存按需求在 192–384 个解码图像间调整；旋转和更高 DPR 不因容量不足反复读取。
- 原图边缘透明填充只在首次解码时裁切；布局尺寸向外取整，避免半透明或细缝。
- 同一帧的指针事件合并，按钮约 180 ms 过渡并遵守减少动态效果偏好；触摸立即打断动画。地点空间索引减少每帧扫描，聚合和地名布局约 100 ms 刷新，松手立即刷新。
- 原包名、localStorage origin / 记录键、备份格式、签名密钥均沿用；版本 0.1.1 / versionCode 2。

## 原因与验证边界

原版 DPR 2.625 下 256 px 瓦片被拉到约 417 物理像素。阻塞新级别图片后，已解码高清层立即移除，新图片 naturalWidth 仍为 0；原概览包装层高度为 0，最大倍率主图层约 59,597 × 49,665 CSS px，地名反向缩放。

桌面未能复现 Android 截图的同形状 GPU 缺块，不能把它归咎于丢失 APK 资源：原包资源本身完整。本次移除大面积缩放层、保留已解码地形并限制合成范围；新版用户手机仍需复测。

曾比较视口 Canvas，每帧整屏重绘的生产性能明显较慢，因此最终交付使用图片合成；Canvas 仅用于边缘图片首次裁切。
