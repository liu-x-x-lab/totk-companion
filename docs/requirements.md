# 需求基线

日期：2026-10-07。状态：按用户追加要求更新，包含三层真实地图与完整固定地点分类。

## 原始目标

做一个《塞尔达传说：王国之泪》的辅助 App，主要在手机上使用。可以看地图、放大地图、查看武器装备和耐久、查看地图上的怪物分布。先建立独立项目目录、初始化项目结构和需求。

## 本次技术选择

先做手机优先的网页 App，兼容桌面浏览器。用户已指定 Android，提供 Android 8.0 及以上的原生 WebView 离线 APK；网页开发预览继续保留。初始方案为纯前端 React + TypeScript + Vite；本地资料仓库、本地存储，不需要登录。

## 数据和耐久的边界

“装备耐久”分两部分：图鉴中的基础耐久，以及玩家在本 App 中手动记录的剩余耐久。当前已接入固定基础属性，新记录默认预填基础耐久；玩家可按词条、融合与实际消耗调整。App 不自动读取主机状态。若后续需要导入存档或读取具体背包，另行确定数据获取方式和支持版本。

地图已替换为社区真实资料，包括天空、地表和地底。保留全部源 ID、原始坐标和分类；来源未声明具体游戏版本，因此以社区资料状态展示。310 件基础装备属性由公开数据表对照导入；未知历史装备条目仍为“待核验”。示例文件保留作历史测试参考，不进入运行中的资料仓库。

## 手机使用流程

1. 打开即进入地图，选择天空 / 地表 / 地底。
2. 搜索名称或切换怪物 / 地点筛选，拖动或双指放大。
3. 点击标记查看说明并收藏。
4. 在装备页按类别查资料，按需要手动记录耐久。
5. 在怪物页按种类查地点，点击“地图定位”返回地图。
6. 在收藏页重访收藏、导出记录或导入备份。
