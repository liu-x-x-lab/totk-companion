# 0.1.4 手机远景与快速区域放大验收

日期：2026-10-08。最终打包：04:02 UTC / 北京时间 12:02；局域网全量下载核对：04:04 UTC。版本 0.1.4 / versionCode 5，包名 `app.hyrule.companion`。

## 根因与最终行为

原聚合网格只保证少于 150 个标记，未按倍率分配密度；相邻网格的质心可能使 44 px 触控矩形重叠。点击只固定乘二，没有根据区域范围与浮层调整定位，也没有双击放大入口。

现在小于 4 倍的远景预算最多 32 个标记，用区域图标替代聚合数字；4–12 倍最多 64 个，12 倍起最多 120 个，逐步展开。普通聚合质心过近时合并，选中地点独立显示。中近景最多显示 `99+`，无障碍名称保留精确数量。

点击聚合结合真实点位范围与可用地图区域定位，一次至少推进两倍，远景一次进入至少 4 倍；最大倍率继续使用重合地点列表。空白地图两次短轻点 / 鼠标双击放大所点区域，拖动、双指、长按和取消不能作为双击。

截图检查发现重要地区文字沿用旧的“忽略标记”规则，会被区域图标压住，已改为优先上下避让；没有可用位置时仍保留重要名称。玩家存储键、schemaVersion、原始地点 ID / 坐标、离线 origin 和签名均未更换。
