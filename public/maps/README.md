# 三层地图资源

`Ground/2/`、`Sky/2/`、`Depths/2/` 是来源项目的真实概览瓦片，每层 3 × 3 张。来源、坐标轴与投影见 `docs/sources.md` 和 `public/data/manifest.json`。

前端在本地概览上按可见区域请求上游的 3–7 级高清瓦片，概览和地点资料无需依赖在线查询；完整高清离线下载尚未实现。

原生画布 24000 × 20000，世界范围 X -6000 至 6000、Z -5000 至 5000。显示画布保持 6:5，不拉伸坐标。

更新命令：`python3 scripts/sync-data.py --tiles`。
